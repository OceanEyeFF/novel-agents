# Writer Room v0.2 架构升级草案

## 目标

把系统从“Scene 功能流水线”升级为“Chapter 导演制小说工坊”。

## 新增模块

- **Orchestrator**：常驻中心调度、状态机、返工路由
- **Prose Director**：把 beats 转成小说表达方案
- **Chapter Assembly**：组装整章并补过桥段、呼吸段、余波段
- **Novel-Novelize Skill**：承接 prose brief、小说化扩写、抗摘要化检查

## 新工作流

```text
章纲
→ scene beats
→ prose brief
→ scene skeleton
→ prose expansion
→ scene critic
→ chapter assembly
→ chapter critic
→ archive
```

## 状态机摘要

| 状态 | 含义 | 下一个默认动作 |
|------|------|----------------|
| planned | 章纲已建立 | Scene Planner 生成 beats |
| beat_ready | beats 完成 | Prose Director 生成 prose brief |
| prose_ready | prose brief 完成 | Writer 写 skeleton |
| drafting | 正在写作 | Writer 执行 expansion |
| review_failed_minor | 小问题 | Writer 局部修文 |
| review_failed_major | 大问题 | Writer 重写 scene / 补 bridge |
| replan_required | 规划问题 | Scene Planner 或 Architect 重规划 |
| scene_approved | 单 scene 通过 | Orchestrator 组章 |
| chapter_assembling | 章级组装 | Critic 做 chapter-level 审查 |
| chapter_approved | 本章通过 | Archivist 归档 |
| archived | 已归档 | 进入下一章 |

## Critic 评分面板

- `scene_density`
- `novelness`
- `chapter_cohesion`
- `script_like_risk`
- `required_action`

## Skill 接口草案

### `novel-novelize`
- `create_prose_brief(scene_beat, character_constraints, style_profile)`
- `expand_scene_prose(scene_skeleton, prose_brief)`
- `bridge_adjacent_scenes(previous_scene, current_scene, chapter_goal)`
- `densify_summary_like_paragraphs(scene_text, risk_report)`

### `novel-draft` 扩展建议
- `draft_scene_skeleton`
- `expand_scene_prose`
- `bridge_adjacent_scenes`
- `densify_description`

### `novel-verify` 扩展建议
- `score_scene_density`
- `score_novelness`
- `score_chapter_cohesion`
- `detect_script_like_risk`

## 成功标准

- 章节可自动跑完 70% 以上内循环
- 单 scene 正文均值提升到 900–1500 字
- chapter critic 能识别并修复“片段拼接感”
- Critic 能稳定标记“剧本化风险”并给出结构化返工动作
