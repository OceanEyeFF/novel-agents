# novel-snapshot

管理小说项目的版本快照，支持创建、回滚、对比。

> 执行前提：必须先锁定 `novel_id`，快照只能包含当前 `projects/{{novel_id}}/workspace/` 下的文件。

## When to Use

✅ **USE this skill when:**

- 每次完成章节后需要保存版本
- 需要回滚到之前的版本
- 需要对比两个版本的差异
- 需要查看历史变更记录

## 快照类型

### 1. 章节快照
- 每次完成一章后自动创建
- 包含: 章节正文 + 章节摘要 + 评审报告

### 2. 规划快照
- 每次重大规划变更后创建
- 包含: 卷纲 + 章纲 + Scene Beats

### 3. 状态快照
- 每次状态重大变更后创建
- 包含: 角色状态 + 时间线 + 伏笔表

### 4. 完整快照
- 项目关键节点创建
- 包含以上全部

## 创建快照

### 手动创建

```bash
# 创建章节快照
# 文件: projects/{{novel_id}}/workspace/snapshots/chapters/snapshot-{{时间戳}}-{{章节}}.md

# 命名规范
snapshot-{{类型}}-{{ID}}-{{YYYYMMDD}}
```

### 自动触发

- 章节从"草稿"变为"通过"时
- 章纲发生重大变更时
- 角色状态发生重大变化时
- 用户手动触发时

## 回滚操作

### 回滚条件
- 当前版本出现致命错误
- 需要回到之前的某个状态
- 用户明确要求回滚

### 回滚流程

1. **确认回滚点**
   ```
   读取: projects/{{novel_id}}/workspace/snapshots/index.md
   找到目标快照ID
   ```

2. **评估影响**
   - 会影响哪些文件？
   - 有哪些后续变更会被覆盖？
   - 是否需要备份当前版本？

3. **执行回滚**
   - 从快照包中恢复文件
   - 记录回滚日志
   - 通知相关 Agent

4. **验证**
   - 检查关键文件是否恢复正确
   - 确认状态一致性

## 版本对比

### 对比维度

| 维度 | 对比内容 |
|------|----------|
| 正文变化 | 字数增删、段落调整 |
| 状态变化 | 角色情绪、关系变化 |
| 规划变化 | 章纲变更、伏笔投放 |

### 对比输出

```markdown
## 版本对比报告

### 快照A: {{ID}}
### 快照B: {{ID}}

### 正文变化
+ 新增: {{字数}}
- 删除: {{字数}}
~ 修改: {{位置}}

### 状态变化
- 角色A: {{变化}}
- 角色B: {{变化}}

### 伏笔变化
+ 新增: {{伏笔}}
~ 状态变更: {{伏笔}}
```

## 快照存储

### 目录结构

```
projects/{{novel_id}}/workspace/snapshots/
├── index.md              # 当前小说快照索引
├── chapters/            # 章节快照
│   └── snapshot-{{...}}.md
├── plans/               # 规划快照
├── states/              # 状态快照
└── full/                # 完整快照
```

### 清理策略

- 章节快照: 保留最近10个
- 规划快照: 保留最近5个
- 状态快照: 保留最近20个
- 完整快照: 保留关键节点（3个）

## 注意事项

1. **定期创建**: 重要节点一定要有快照
2. **注释清晰**: 快照原因要写清楚
3. **不要频繁回滚**: 每次回滚都可能丢失后续内容
4. **备份当前**: 回滚前先备份当前版本
