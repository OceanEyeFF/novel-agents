# Novel Novelize

Use this skill when a scene plan is structurally correct but risks reading like a screenplay, beat sheet, or event summary.

## Workflow

1. Read the approved `scene beat` and current `character constraints`.
2. Produce a **prose brief** before drafting final prose.
3. Ask the writer pass to generate a **scene skeleton** that preserves event order.
4. Run a **novelization expansion** pass that adds texture without changing plot facts.
5. Run a lightweight **script-like risk** check and request densification if needed.

## Required prose brief fields

- `emotional_core`
- `narrative_focus`
- `slow_beats`
- `sensory_targets`
- `inner_monologue_targets`
- `dialogue_purpose`
- `hidden_information`
- `paragraph_rhythm`
- `prose_length_plan`

## Expansion rules

During expansion, add only the following kinds of material unless the chapter plan explicitly allows more:

- environment anchors
- body sensations
- inner misreads or associations
- dialogue subtext
- pacing pauses and aftershocks
- texture details that increase presence

Do not:

- invent new plot turns
- reveal hidden information early
- merge multiple scenes into one draft
- replace POV discipline with omniscient summary

## Script-like risk heuristic

If 3 or more of the following are true, mark the scene as high risk and request revision:

- dialogue carries nearly all progression
- paragraphs only report action or information
- emotion is named but not experienced
- the setting is mentioned but not dramatized
- dialogue is purely functional with little subtext
- paragraph lengths are mechanically uniform
- transitions end abruptly without emotional residue
- POV is nominally present but not sticky on the page

## Repair checklist

When risk is high, add at least:

- 1 environment anchor
- 1 body sensation
- 1 inner misread or memory echo
- 1 slowed beat
- 1 non-functional texture detail
