# novel-canon

管理小说核心设定（Canon Bible），所有创作必须遵循的事实。

## When to Use

✅ **USE this skill when:**

- 查询世界观、设定、规则
- 确认某设定是否已有明确规定
- 需要引用 canon 中的禁止事项
- 规划新情节时确认不冲突

## 文件位置

- `canon/bible.md` - 核心设定（世界观、剧情主线、文风、禁止事项）
- `canon/characters/` - 各角色基础设定

## 常用操作

### 读取完整 Canon Bible

直接读取文件：

```
read: canon/bible.md
```

### 读取特定角色设定

```
read: canon/characters/{{角色名}}.md
```

### 列出所有角色

```
exec: ls novel-workspace/canon/characters/
```
